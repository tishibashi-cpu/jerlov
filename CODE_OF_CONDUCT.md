# Code of conduct

This project follows the [Contributor Covenant][covenant], version 2.1.

In short: treat other people with respect. Harassment, insults, and personal
attacks are not acceptable, whether in issues, pull requests, or anywhere else
connected with the project.

Disagreement about a coefficient, a method, or a design decision is welcome
and is most of what happens here. Disagreement about a person is not.

Report a problem to the address in `CITATION.cff`, or by opening an issue if
it can be discussed in public. Reports will be handled privately and in
confidence.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
