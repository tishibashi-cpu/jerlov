# Primary sources

The files in this directory are **not** kept in version control. They are the
inputs from which `jerlov/data/*.csv` is generated by `tools/`. Journal
articles cannot be redistributed; the figshare dataset can be, but is large.

Obtain them as follows, then run the scripts in `tools/`.

## Required to regenerate the tables

| Path | What | Where |
|---|---|---|
| `sources/20290782/` | Dstl IOP dataset, **Version 3** | figshare DOI `10.6084/m9.figshare.20290782` (Crown copyright, Dstl; Open Government Licence v3.0) |
| `sources/21710252/` | Dstl depth profile dataset | figshare DOI `10.6084/m9.figshare.21710252`. **Not the DOI in the paper's Data Availability Statement, which points to an unrelated dataset; see DATA.md section 13** |

Only two files inside it are read: `ip_jerlov.csv` and
`20221121-Dstl_MIOP_analysis_v3.xlsx`, plus `op_STEP_6_a.csv` and
`op_STEP_6_b.csv`.

`tools/build_austin1986.py` needs no input: the values are transcribed from
the paper and are literals inside the script, checked against the paper's own
Eq. (6) at run time.

**Jerlov (1968)** *Optical Oceanography*, Elsevier Oceanography Series Vol. 5,
Tables XX and XXI, has been obtained and transcribed into
`jerlov1968_kd.csv` and `jerlov1968_total_irradiance.csv`. **No DOI exists**;
the DOIs `10.4319/lo.1968.13.4.0731` and `10.1126/science.163.3862.64.a` are
reviews of the book, not the book. Not held by the University of Tsukuba
library.

sections 2 and 5.
