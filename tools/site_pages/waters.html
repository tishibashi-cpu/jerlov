Ocean optics · the Jerlov types

The waters side by side

A Jerlov type is a name, not a measurement. Several papers give numbers for the same type, and they do not agree: some measured the water, some inverted the light, one replaced a type's values with pure sea water. Pick a type to see every source the package has for it on one set of axes, or a source to see all its types.

The sources, and what the package says of each

Every value on this page is what jerlov returns from water(type, source=...), every 5 nm from 350 to 700 nm or at the source's own wavelengths where it gives fewer; nothing is drawn where a source gives nothing. Williamson & Hollins measured from 412 to 715 nm, so their lines start at 415 nm. The caveats are the package's own, as jerlov.SOURCES states them. Where the numbers came from is in DATA.md, and why the package keeps the sources apart in DECISIONS.md.
